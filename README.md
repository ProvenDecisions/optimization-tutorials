# Optimization tutorials, the math explained line by line

Short lessons on optimization and the calculus behind it, from [ProvenDecisions](https://proven-decisions.ai/?ref=github): the idea in plain
words, the math with a comment on every formula, and a worked example. **New lessons are added every month**, starting
1 December 2026: ⭐ star or 👀 watch this repository to hear about them.

Can't wait? The free tutorials are already on the site: [Learn](https://proven-decisions.ai/learn?ref=github) ·
[Calculus refreshers](https://proven-decisions.ai/refreshers?ref=github) · [Glossary](https://proven-decisions.ai/glossary?ref=github)

Runnable examples: [optimization-examples](https://github.com/ProvenDecisions/optimization-examples) (Jupyter
notebooks, each answer checked by a solver).
